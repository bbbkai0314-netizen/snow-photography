# SnowSurfStudio｜內容企劃與渠道改寫

這是**行銷部門的 Skill**，不是 Agent 或獨立部門。主線 CEO 收到跨渠道內容任務時，交行銷部門使用；`marketing-brand-agent` 統一切角，`content-agent` 寫長文，`social-agent` 寫社群版本，`seo-agent` 提供搜尋意圖，`market-evidence-agent` 查核外部主張，`content-quality-reviewer` 做最後檢查。只使用任務需要的角色。

## 輸入

Ellie 提供的主題、原文或素材，以及受眾、目的、已確認的服務事實與可用照片。缺少非關鍵細節時可合理規劃；涉及價格、日期、名額、路線、服務可用性、照片或客戶故事使用權時，標記待確認，不自行補出承諾。

## 流程

1. 用一句話定義受眾、核心訊息與本次目標；選定**一個共同 CTA**，明確指出指向 LINE、預約頁或其他 Ellie 指定位置。
2. 列出可核對的事實、需要來源的主張、可用素材與尚缺素材。雪場、交通、營業資訊與市場數字須有可追溯依據；查不到時不寫成事實。
3. 先產出內容企劃：各渠道的讀者意圖、切角、篇幅與素材需求。網站承載完整脈絡；IG 聚焦畫面與精簡訊息；Facebook 可加入較完整的情境與互動提問。保留同一核心訊息，不機械複製段落。
4. 如產出部落格、Journal 或長文，**先讀** [`../Article_Writing_Spec/SKILL.md`](../Article_Writing_Spec/SKILL.md)，自動判斷 MODE A／B／C，再寫網站版本。不要要求 Ellie 重給文章架構。
5. 產出網站、IG、Facebook 各自的草稿，以及每版所需照片／圖卡、標題、連結或 UTM 建議。只在符合渠道目的時提供 hashtag。
6. 檢查三版的事實、品牌語氣、單一 CTA 與素材權利；列出待 Ellie 確認事項。產物是可審閱草稿，正式發布與網站部署須依 [`../../13_SOP_Workflows/approval-queue.md`](../../13_SOP_Workflows/approval-queue.md) 取得該版本核准。

## 交付格式

- **企劃摘要：**受眾、目標、核心訊息、共同 CTA、依據與待確認事項。
- **網站版：**標題、摘要、正文草稿；如為長文，標明 MODE A／B／C。
- **IG 版：**圖卡或照片順序建議、caption 草稿。
- **Facebook 版：**貼文草稿與互動引導。
- **素材清單：**已有素材、缺少素材、使用權待確認項目。
- **交付前 QA：**事實／語氣／CTA／連結／權利的檢查結果。
